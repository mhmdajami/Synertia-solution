# Synertia Solutions

Bilingual industrial engineering landing site built with React, Tailwind CSS, and Vite.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The generated `dist` directory can be deployed directly to Vercel, Netlify, or any static hosting provider.

## GitHub Pages

The included GitHub Actions workflow deploys the site automatically whenever the `main` branch is updated.

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **GitHub Actions** as the source.
3. Push the project to `main`.

The public URL will be:

`https://mhmdajami.github.io/Synertia-solution/`
